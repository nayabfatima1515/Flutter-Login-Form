This project is a Flutter-based login screen that demonstrates basic UI building, form validation, and navigation to another screen (HomePage). It is designed as part of an internship task to practice Flutter development fundamentals.

The login page features:
Email and password input fields
Form validation for email format and password length
Forgot password text
Gradient login button
Social login icons (Facebook and Google placeholders)
Responsive design using MediaQuery and Stack# Flutter-Login-Form

Technologies Used:
Flutter
Dart
Widgets used: Stack, SingleChildScrollView, Container, TextFormField, ElevatedButton, Row, Column, Icon
Navigation: Navigator.push()

Notes
This is a frontend-only login screen. No backend or authentication API is implemented.
Social login buttons are UI placeholders and do not perform real authentication.
Designed for internship task submission to demonstrate Flutter UI and form validation skills.
